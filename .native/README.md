# 资源加载优化

本目录包含资源加载优化的原生源码、构建脚本和离线测试。

| 配置项 | 功能 | 默认值 |
| --- | --- | --- |
| `native_zip` | 资源解压加速：使用 libdeflate 解压满足条件的完整 ZIP 条目 | 开启 |
| `native_fill` | 资源初始化加速：将两处内存填充循环替换为 `rep stosb` | 开启 |

运行环境为 Windows x64 LuaJIT。不满足平台条件时跳过原生功能，索引和迁移功能继续按各自配置工作。

原生模块在 modmain 阶段启动，仅覆盖之后发生的加载。无需往 bin64 放代理 DLL。
补丁按进程安装，不依赖 Lua 回调，不随 Lua VM 重建重复安装；启停选项或更新模块后须完整退出游戏进程。

## 兼容性检查

不绑定 EXE 哈希、游戏版本号或固定函数地址。
两处填充循环必须各自唯一匹配；ZIP 读/关闭函数使用带调用地址通配符的代码特征，同时核对私有布局和读取语义。
无关函数、资源或链接地址变化不影响匹配。相关实现改变时只跳过对应功能并记录日志，不猜测新布局。
游戏更新改变相关实现后，需要重新检查特征和布局。

ZIP 快速路径仅处理首次完整读取、压缩数据不超过 64 MiB 的普通 DEFLATE 条目。分段读取、stored、raw、内存不足、读取失败等交给原版。
所有逻辑状态在成功解压后统一更新。当前游戏的 ZIP 读/关闭函数不执行 CRC，生产路径保持该行为。
离线验证仍比较 CRC 和输出长度，避免将解码错误计作性能收益。

填充补丁保留原循环最终寄存器、标志位、栈上计数和指针。
安装时暂停可枚举的其他线程；若无法暂停或线程位于补丁区，则跳过两处填充修改。
ZIP 跳板由 MinHook 发布，只在完整的读/关闭函数特征各自唯一匹配时安装；入口已被改写时跳过。
重复进入 Lua VM 时按首次请求配置判断设置是否变化；某项安装失败不视为配置修改。

## 构建

需要安装 Visual Studio 2022，并包含 MSVC x64 C++ 工具链、Windows SDK 和 CMake 工具。
依赖的 libdeflate 和 MinHook 源码已包含在 `vendor/` 中。

在项目根目录打开 PowerShell，指定构建目录后运行：

```powershell
$buildRoot = Join-Path $env:TEMP "dst_fastloading-native-build"
& .\.native\build.ps1 -BuildRoot $buildRoot -Install
```

`-BuildRoot` 指定构建中间文件和测试程序的输出目录，可替换为自己的工作目录。
脚本会配置 x64 Release 构建、编译原生模块并运行 ZIP 快速路径回归测试。
测试通过后，`-Install` 将生成的 DLL 复制为项目中的 `native/dst_fastloading_native.dll.pkg`；省略此参数则只构建和测试。

## 加载与发布

启动时加载器从发布包生成运行 DLL；已加载的同目录模块复用，不覆盖在用文件。发布时排除运行 DLL 和日志。
发布包路径为 `native/dst_fastloading_native.dll.pkg`。
第三方许可证分别位于本目录的 `vendor/libdeflate/COPYING` 和 `vendor/minhook/LICENSE.txt`。
更新发布包后，需要完整退出游戏再启动，才能加载新版本。

## 离线验证

以下路径均相对于本目录：

- `tests/test_zip.cpp`：构建脚本自动执行，检查 ZIP 快速路径、状态更新和失败回退。
- `tests/test_fill.py`：使用 Unicorn 检查两处原/新指令的寄存器、标志位、栈与内存结果。
- `tests/test_loader.py <临时目录>`：使用 `lupa.luajit21` 检查中文路径、真实 Win32 加载、VM 销毁重建、源包更新、缺包、损坏包、同名模块冲突与工坊目录解析。临时目录用于存放测试副本，应选择独立的空目录。
- `tests/test_patterns.py <游戏 EXE>`：只读检查特征唯一性、调用地址变化及布局变化时的匹配行为。

隔离加载器测试的宿主不是游戏，原生入口必须返回 0 并记录未修改引擎，不通过重命名测试进程绕过检查。
离线验证不能替代游戏内测试。更新后应检查启动、进服、地洞迁移，以及退回菜单后重新进入的行为。

## 日志

原生日志位于实体模组目录的 `native/fastloading_native.log`，记录特征检查、补丁安装和跳过原因。
游戏日志中的启用结果为位掩码：`0` 表示均未安装，`1` 表示仅 ZIP 解压加速，`2` 表示仅内存填充加速，`3` 表示两项均已安装。
